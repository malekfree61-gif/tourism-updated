# ExoToura Guide (الشات بوت)

- الأيقونة الدائرية الذهبية أسفل يمين كل الصفحات (html/chatbot.js) - بتشتغل ثنائية اللغة (عربي/English).
- بتجيب معلوماتها من: صفحات الموقع + PROJECT_DOCUMENTATION.md + data.json (27 محافظة) + معلومات عن الأماكن الأثرية.
- شغالة فوراً بدون أي إعداد (قاعدة معرفة مدمجة).
- لتفعيل ذكاء اصطناعي حقيقي على Vercel: أضف متغير بيئة ANTHROPIC_API_KEY (api/chat.js)، والشات هيستخدمه تلقائياً.
  اختياري: CLAUDE_MODEL لتغيير الموديل. لو المفتاح غير موجود يرجع تلقائياً للقاعدة المدمجة.
- لا تضع المفتاح داخل أي ملف JS في المتصفح أبداً.
